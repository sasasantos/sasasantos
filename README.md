      <h3 align="center">📚 Lumos Livraria</h3>
      <p>Plataforma web completa desenvolvida para a gestão e controle administrativo de uma livraria, integrando persistência de dados relacional e interface responsiva.</p>
      
      <h4>⚡ Funcionalidades do Sistema:</h4>
      <ul>
        <li><b>Gerenciamento de Livros:</b> Cadastro, edição e remoção do acervo.</li>
        <li><b>Cadastro de Clientes & Login:</b> Autenticação e controle de sessões.</li>
        <li><b>Categorização:</b> Organização dinâmica de acervo e coleções.</li>
        <li><b>Controle de Vendas & Dashboard:</b> Visualização de métricas e vendas.</li>
        <li><b>Banco de Dados Relacional:</b> Mapeamento via ORM SQLAlchemy.</li>
