## 🚀 PROJETO EM DESTAQUE

<div align="center">

# 📚 LUMOS LIVRARIA

</div>

O **Lumos Livraria** é um sistema web desenvolvido para auxiliar no **gerenciamento de uma livraria**, permitindo organizar informações e operações de forma centralizada.

### 🛠️ Tecnologias utilizadas

`Python` • `Flask` • `SQLite` • `SQLAlchemy` • `HTML` • `CSS`

### ✨ Principais funcionalidades

- 📚 Gerenciamento de livros
- 👥 Cadastro de clientes
- 🏷️ Organização por categorias
- 🛒 Controle de vendas
- 🔐 Sistema de login
- 📊 Dashboard
- 🗄️ Integração com banco de dados
